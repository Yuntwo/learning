Agent 质量工程
Agent 评测
到底该怎么体系化做？
把随机、黑盒、多步级联的智能行为，收敛成可发布、可回归、可复盘的工程质量。
1
先分 Agent 类型，再定指标
对话型、任务型、Skill 型的完成标准不同，不能用一套万能分数硬评所有系统。
2
不能只看最终答案
还要看工具调用、参数构造、执行路径、风险控制和多次运行的一致性。
3
规则、Judge、人审分层打分
硬条件尽量规则化，语义和策略交给 Judge，高风险与冲突样本再人工兜底。
4
评测闭环要通到修复动作
badcase 不是报告终点，最终要落成根因标签、回归集和结构化行动项。
