算法题速记

Java 转 Go
刷题语法差异

别把时间耗在语法卡顿上。先把最常用的 函数签名、切片、map 判存在 和 DFS 写法 固定成模板。
01

函数签名变了

func f(nums []int) int
类型写在变量名后，返回值放最后。

02

没有 while

双指针、滑窗、二分都改成
for condition {}

03

数组 ≠ 切片

[]int 才是刷题主力。
append 后一定记得接返回值。

04

map 要配 ok

Go 没有 containsKey。
判断存在要写 v, ok := mp[x]

最值得先记住的一句话
Java 转 Go 刷题，真正要迁移的不是算法思路，而是那几套最常用的语法模板。
