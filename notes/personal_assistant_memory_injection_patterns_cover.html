AI 助理架构
用户记忆
到底怎么进大模型？
别把“记忆能力”简单理解成 system prompt 变长。成熟实现更像分层存储、按需检索、选择性注入。
1
稳定偏好可常驻高优先级提示层
语言、风格、专业背景这类低频变化信息，适合长期作为默认行为约束。
2
长期记忆更适合按需检索
系统会根据当前问题，只取少量高相关记忆，而不是把全部历史永久带上。
3
部分画像只在业务层生效
它们可能只影响模型选择、回复长度、工具路由，不一定直接原样喂给模型。
4
核心能力是上下文编排
一个助理是否“懂你”，很大程度取决于 memory system、检索策略与上下文构建质量。
