DSH 插件观察

我做了一个
Langfuse Trace 插件

主角先放最前面：dsh-langfuse-plugin。沿官方 telemetry seam 做 sidecar，把 DSH 会话过程接进 Langfuse 更完整的观测体系。
主角项目
Yuntwo / dsh-langfuse-plugin
重点不是替代官方 trace，而是补齐 trace / observation / score / dataset 这条工程链路。
参考 01

dsh-visualize

让模型在对话里直接生成 交互 UI 卡片，说明 DSH 不只会输出文本。

参考 02

dsh-stock-watch

把 DSH Web UI 改造成 垂直业务工作台，常驻面板这条路很有意思。

参考 03

dsh-agent-teams

把单会话扩成 多 Agent 协作团队，能看到编排和调度层的想象空间。

如果只记住一句话
DSH 插件开始有生态感了，而观测类插件会是里面很有工程价值的一条线。
